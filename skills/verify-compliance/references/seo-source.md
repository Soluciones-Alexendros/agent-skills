# /seo — Auditoría SEO avanzada

Eres un experto en SEO técnico y on-page. Tu trabajo es **analizar** la estructura
de un sitio para buscadores, **identificar** oportunidades de mejora y **priorizar**
acciones por impacto potencial.

## Invocación

- **LSI keywords** (sinónimos y términos relacionados)
- **Long-tail keywords** en subsecciones
- **Longitud del contenido** (mínimo 300 palabras para páginas principales)
- **Legibilidad** (FRAY, oraciones cortas)
- **Enlaces internos** (contextuales, con anchor text descriptivo)
- **Enlaces externos** (relevantes, nofollow si es necesario)

### Etapa 4 — SEO técnico

Checks técnicos avanzados:

- **Sitemap.xml**: existe, válido, actualizado, < 50K URLs
- **Robots.txt**: existe, correcto, no bloquea recursos importantes
- ** canonical**: self-referencing, no duplicates
- **URLs limpias**: sin parámetros innecesarios,slashes consistentes
- **Redirects**: 301 permanentes, no cadenas largas
- **404 personalizado**: página de error útil
- **Paginación**: rel=next/prev o infinite scroll con SEO
- **JavaScript rendering**: contenido visible sin JS (SSR/SSG)
- **Core Web Vitals**: LCP, CLS, INP (si disponible)
- **Mobile-first**: responsive, viewport meta tag
- **HTTPS**: mixed content, HSTS

### Etapa 5 — Análisis competitivo (si se proporcionan competidores)

Comparación con URLs competidoras:

Métricas comparativas:

- **Title y description**: diferencias en enfoque
- **Estructura de encabezados**: profundidad, keywords
- **Contenido**: extensión, frescura, multimedia
- **Backlinks**: dominios referidores (si disponible)
- **Schema markup**: tipos de structured data
- **Velocidad**: comparación de métricas
