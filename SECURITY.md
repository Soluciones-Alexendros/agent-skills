# Security policy

Report a vulnerability in a skill, a bundled script, or the validators of this repository through GitHub private vulnerability reporting:

https://github.com/Soluciones-Alexendros/agent-skills/security/advisories/new

Do not open a public issue for an exploitable finding in a script that runs on a host. Include the skill name, the script path, the affected version (`package.json` or `metadata.version`), and a reproduction.

We acknowledge reports and, when a fix ships, credit the reporter in the changelog if they want that.
